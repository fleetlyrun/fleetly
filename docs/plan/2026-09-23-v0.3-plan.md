## 3. W0 开放问题清单（设计裁决轮议题预览）

1. **人类认证形态**：密码+会话（浏览器原生体验）vs 用户级长 token（复用现有 Bearer 面）vs 两者（密码登录换会话 token）；CLI/Console/API 三面一致性。
2. **角色粒度**：预置角色集（owner/admin/operator/viewer?）vs 自定义角色+权限矩阵；资源作用域（全库 vs per-app）是否进首发。
3. **审计留存与读面**：留存窗口分级（安全审计 vs 操作审计）、导出形态（CSV/流）、不可篡改性边界（SQLite 单文件的现实约束——诚实口径）。
4. **FZ-12 SSH host key 钉位**：多用户下的 git push 面加固形态（known_hosts 策略/首次钉定/变更告警）。
5. **商业分界提案**：哪些能力免费/哪些付费（架构红线要求提前公开定义）。
6. **既有单操作员迁移**：存量安装升级到多用户形态的默认路径（首用户=admin?bootstrap token 映射?）。

## 4. 明确不做（v0.3 范围外）

- PR 预览环境、官方模板目录、Tunnel 接入（随 AI/Agent 线整体后移，v0.4+ 候选）；
- k3s driver/自研 node 协议/通用插件系统（长期不做清单不变）。
