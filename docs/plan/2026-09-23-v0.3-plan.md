## 1. 定位与裁决

**v0.3 主题 = 团队与商业基线**：把单操作员平台升级为多用户/角色/审计留存的团队形态（商业版候选面先行），随后补生产深化票。横切红线沿用 v0.2（预算口径〔opt-in 不占顶〕、单写点、契约纪律、文档先行）。

| # | 裁决 | 结论 |
|---|---|---|
| V3-1 | v0.3 主线（用户直裁 2026-09-23） | **先 C（团队/RBAC/审计留存）后 B（生产深化）**——非架构原文的 AI/Agent 排序 |
| V3-2 | E2 MCP | **继续降低优先级**（v0.2 暂缓〔D-W5-1〕后再降——退出 v0.3 主线；D10 纪律条款继续随迁挂账，重启时机随真实需求） |
| V3-3 | 跨节点互备 DR | **继续挂账**（对比设计也不在 v0.3 启动） |
| V3-4 | v0.2 遗留挂账 | **顺手收**（8423 根治等随主线票带出，不单独立波） |

## 3. W0 开放问题清单（设计裁决轮议题预览）

**六问已全部裁决（2026-09-23 W0 裁决轮 + 用户补充需求选型，实录见 [RBAC 设计 §13](../design/2026-09-23-rbac-teams.md)）**：

| # | 议题 | 结论（裁决号） |
|---|---|---|
| 1 | 人类认证形态 | 口令+服务端会话（Console）+ PAT（CLI/CI）；CLI 登录=粘贴 PAT，device flow 挂账（D-W0-1） |
| 2 | 角色粒度 | 预置四档 viewer/developer/admin/owner + 平台管理员标志；**Project 层角色 = 队内覆写形**（D-W0-2 修订 2026-09-23 成本复盘：仅限团队成员、双向覆写、owner 不可覆写、可见性零级联；A 形全量挂账）；资源作用域 = Team/Project 归属而非 per-app（D-W0-2/3） |
| 3 | 审计留存与读面 | 90 天可调（platform_settings audit.retention_days）+ Console 审计页 + CLI 导出 CSV（D-W0-6） |
| 4 | FZ-12 SSH host key 钉位 | 指纹披露 + git.hostkey_changed 变更事件 + CLI `fleetly git fingerprint` 核对（D-W0-8） |
| 5 | 商业分界 | **开源全功能**（自托管不设团队/项目/成员上限）；付费=托管云+企业件（SSO/LDAP/审计外发 SIEM/合规报告/优先支持）（D-W0-7） |
| 6 | 既有单操作员迁移 | **无迁移负担**（用户澄清 2026-09-23：仅一处 staging 可清空重建）——v0.3 = fresh-install 版本（无 v0.2 升级路径）；首用户=平台管理员+个人队，bootstrap token 注册即吊销（D-W0-5 修订） |

## 4. 明确不做（v0.3 范围外）

- E2 MCP（V3-2 再降级；重启随真实需求重新裁决）；
- 跨节点互备 DR（V3-3 继续挂账）；
- PR 预览环境、官方模板目录、Tunnel 接入（随 AI/Agent 线整体后移，v0.4+ 候选）；
- k3s driver/自研 node 协议/通用插件系统（长期不做清单不变）。

## 5. 执行纪律

沿用 v0.1/v0.2：只从本表取票；票据完成定义=验收全勾+设计未偏离；发现设计缺口停下补裁决；还原点+阶段验收门（subagent-sequential-implement）；每波收口回填 §6。
