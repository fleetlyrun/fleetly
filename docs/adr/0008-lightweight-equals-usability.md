# 元裁决继承：易用性 = 轻量（Dokploy 地板条款已废止）

继承归档 ADR-0008 用户直裁原文精神："只轻量但不好用就没有意义"。红线是多容器重栈，不是组件本身——单核轻量组件（VictoriaLogs、zot、traefik）可以默认捆绑；默认捆绑面守 idle 预算（600MB 为参考默认值）。本条原为"所有功能取舍的最高仲裁"；**ADR-0010 起 DX 为第一权重仲裁，本 ADR 的预算口径与红线降级为参考默认，以实测校准**。

2026-09-30 用户直裁：**废止"体验对标 Dokploy 地板、Dokploy 没有且无硬需求承诺的机制一律不做"条款**——fleetly 不再以任何单一竞品的现有功能面为天花板。替代的功能取舍原则由竞品深调报告（`docs/research/2026-09-30-competitive-deep-dive.md`）重新推导。
