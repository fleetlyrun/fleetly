# 控制面状态语义整套继承（SQLite + 单写者 + Outbox + Replay 回滚）

> 2026-09-30（ADR-0010）：本 ADR 所列继承语义降级为**参考默认**，待竞品深调以 DX 透镜逐项重估；推翻时以新 ADR 记录。

归档项目两周真机迭代验证过的状态语义原样继承，不再重新发明：SQLite(WAL)+goose 为唯一权威存储；每条状态机线单写者 goroutine，四件一拍（状态 CAS + tombstone + Outbox 事件 + 审计）同事务；写前直读冲突 409，观测缓存不参与决策；回滚 = Replay 旧 Revision，永不用编排器原生回滚；漂移检测默认开、收敛默认 opt-in、挂起不被静默撤销；Platform Restore 期间只读；孤儿只登记永不自动删。出处：归档 ADR-0002/0003/0004/0014 及 spike B2/V4 实测。

## Consequences

- 新增状态机必须先答"四件一拍里事件是什么、直读在哪"，否则设计评审不通过。
- 归档仓的四份收敛链拷贝教训同时转化为守卫：循环骨架全平台唯一一份，住在 engine。
